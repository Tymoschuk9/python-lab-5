# Лабораторна робота №5
## Тема: Обробка помилок, файли та серіалізація
## Мета роботи
Сформувати практичні навички створення надійних Python-програм, які коректно працюють із помилками, файловими ресурсами та структурованими форматами даних.
## Опис алгоритму та архітектури (Варіант №3)
Для забезпечення надійності реалізовано патерн "Atomic Write", що гарантує цілісність вихідного файлу навіть при збої програми. Обробка помилок побудована на базі власної ієрархії виключень (Custom Exceptions), що дозволяє розрізняти помилки конфігурації від помилок валідації даних. Використання генераторів та потокових ітераторів дозволяє працювати з великими обсягами даних без переповнення оперативної пам'яті.
## Опис реалізованих функцій та класів
- `DataProcessor`: основний клас для керування логікою обробки.
- `atomic_write`: context manager, що використовує тимчасовий файл для запису, який перейменовується в цільовий файл лише після успішного завершення операцій.
- `DataValidationError`: спеціалізоване виключення, яке зберігає номер рядка та поле, де сталася помилка.
- `process_file`: метод, що зчитує CSV, валідує кожен запис та формує JSON-результат.
## Результати виконання програми
Програма успішно зчитує файл, пропускає рядки з некоректними даними (записуючи про це в лог), а потім записує валідні записи у JSON-файл за допомогою атомарної операції.
## Висновки
Під час роботи було опановано методи безпечної роботи з ресурсами (context managers), механізми обробки помилок (try/except/finally) та принципи Fail-fast. Ієрархія виключень дозволяє робити діагностику помилок більш точною та зручною для розробника.

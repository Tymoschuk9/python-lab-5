# Лабораторна робота №5
## Тема: Обробка помилок, файли та серіалізація
## Мета роботи: Опанувати надійну роботу з файлами, винятками та конфігураціями.
## Опис алгоритму та архітектури (Варіант №3)
Архітектура включає: валідатор, сервіс потокового імпорту, конфігуратор та атомний експортер. Використано патерн "Tolerant mode" для обробки помилок у записах.
## Опис реалізованих функцій та класів
- RecordValidationError: custom виняток для валідації рядків CSV.
- Product: Dataclass для представлення даних інтернет-магазину.
- load_config: завантаження налаштувань з YAML.
- run_import_export: основний pipeline (читання, валідація, логування, запис).
## Результати виконання програми
Програма зчитує CSV, ігнорує записи з від'ємними цінами, логує помилки та записує валідні дані у JSON файл через тимчасовий файл (атомний запис).
## Висновки
Надійність програми забезпечується використанням context managers, винятків та валідації на рівні бізнес-логіки. Атомний запис гарантує цілісність даних при збоях.
